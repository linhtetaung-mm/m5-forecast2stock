# Synthetic batch-scoring snapshot

Use these files with the CA_1 M5 history ending April 24, 2016. The stock counts were constructed from trailing mean units with deliberately varied stock covers. The inbound rows are example confirmed receipts. The three-row service ledger is a synthetic check on fill rate. These files contain no observed inventory, supplier orders or realized service from Walmart. The [batch guide](../docs/BATCH_DEPLOYMENT.md) shows how to run the examples.
